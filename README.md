# GoldPrism

GoldPrism is an Android application for MCX gold commodity derivatives intelligence and execution.

## Run locally

**Prerequisite:** [Android Studio](https://developer.android.com/studio)

1. Open this project in Android Studio.
2. Wait for Gradle sync to finish.
3. Select an Android emulator or connected device and run the `app` configuration.

The app uses simulated market data by default. Keep credentials and local configuration in `.env`; do not commit secrets.
